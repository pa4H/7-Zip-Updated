# Форк 7-Zip 1.0

Базовая версия: **7-Zip 26.05**, исходный коммит `b88c6bc` из
[официального репозитория](https://github.com/ip7z/7zip).
Дата последних изменений: **28 октября 2026 года**.

Это модифицированная версия. Изменения не являются официальным выпуском
Игоря Павлова. Copyright (C) 1999-2026 Igor Pavlov.

## Лицензии и публикация

Большая часть исходников распространяется под GNU LGPL 2.1 или более поздней
версией. Для отдельных файлов действуют BSD 2-Clause, BSD 3-Clause, public
domain и дополнительные ограничения unRAR. Полное распределение лицензий и
уведомления об авторах приведены в исходных файлах:

- `DOC/License.txt`;
- `DOC/copying.txt`;
- `DOC/unRarLicense.txt`.

Эти файлы сохранены без изменений. Новые файлы кода и сборки данного форка
распространяются под GNU LGPL 2.1 или более поздней версией. Оригинальные
уведомления об авторах остаются в исходниках. Изменённые исходные файлы
помечены датой изменения.

Скрипт сборки копирует все три лицензионных файла в пакет программы и создаёт
отдельный ZIP с соответствующими исходниками, включая локальные изменения.
При публикации бинарного пакета разместите рядом этот ZIP с исходниками.
Справка CHM в пакет не входит; лицензионные материалы входят обязательно.

Ограничение unRAR сохраняется: соответствующие исходники нельзя использовать
для воссоздания алгоритма сжатия RAR / разработки совместимого RAR-архиватора.

Кнопка GitHub в окне «О программе» предназначена для GitHub владельца.
До предоставления адреса кнопка отключена. Источник оформления указан в
`THIRD_PARTY_NOTICES.txt`. Публичный репозиторий исходников:
[pa4H/7-Zip-Updated](https://github.com/pa4H/7-Zip-Updated).

## Изменения интерфейса

- Windows 10 и новее; сборочный скрипт готовит вариант x64.
- Английский интерфейс встроен; русский перевод из официального пакета
  26.05 находится в `Lang/ru.txt`. Другие переводы не загружаются и не
  включаются в пакет.
- Меню: «Файл», «Правка», «Вид», «Настройки», «О программе».
- «Настройки» и «О программе» сразу открывают соответствующие окна.
- Убраны «Избранное», «Справка», тест производительности, «История папок»,
  изменение комментария и режимы значков/списка. Чтение архивов с уже
  существующими комментариями сохраняется. Проверка целостности архивов
  остаётся доступной.
- Режим отображения файлов — «Таблица», в том числе при старых сохранённых
  настройках другого режима.
- Добавлены форматы `dd-mm-yyyy` и `dd-mm-yyyy hh:mm`. Первый используется
  по умолчанию; исходные варианты даты остаются в меню.
- «О программе»: `7-Zip 1.0 fork by pa4H (c) 2026`, `Based on 7-Zip 26.05`, copyright Игоря Павлова
  и две кнопки ссылок. Версия форка также задана в ресурсах Windows.
- Удалён пункт «Альтернативные потоки» из меню файлового менеджера.
- В заголовке окна «Настройки» убрана кнопка контекстной справки «?».
- Боковые кнопки мыши перемещают назад/вперёд по истории текущей панели.
  История переходов хранится только в памяти и не является удалённой
  командой «История папок».
- Используется системный `IFileOpenDialog` в режиме выбора папки.
- В обоих сценариях кнопки «Извлечь» добавлены три кнопки последних путей.
  При наведении показывается полный путь. Отмена диалога историю не меняет.
- Для одного архива запоминается базовый каталог. Если корень архива
  содержит что-либо кроме единственной папки, автоматически добавляется
  папка с именем архива. Единственный файл также получает эту папку.
  Неявные каталоги в ZIP и корневой маркер `./` в TAR учитываются.
- История содержит фактические выбранные назначения. Нажатие кнопки истории
  выбирает именно показанный путь. Следующий архив строит предложение от
  отдельно сохранённой базы, без накопления вложенных имён архивов.

## Значки

27 неизменённых исходных иконок архивов скопированы в
`assets/original-icons/archives/`. Их содержимое сверено с оригиналами.
В сборке подключены 27 значков из `assets/filetypes/` с сохранением исходных
идентификаторов ресурсов и ассоциаций. Для составных архивов `.001`
используется `001.ico`. Сами ICO не изменены. 28 октября 2026 года владелец
подтвердил получение разрешения на публикацию с исходниками и распространение
в бинарниках; это подтверждение зафиксировано в `THIRD_PARTY_NOTICES.txt`.

Для кнопок используются неизменённые BMP из `assets/interface/`. Сведения об
авторе и условиях CC BY-NC-SA приведены в `THIRD_PARTY_NOTICES.txt`; тексты
лицензий включены в каталог `licenses/` и пакет программы.

Значок «Вверх» заменён на предоставленный владельцем `up-updated.png` (16×16).
Неизменённый PNG и ICO с теми же пикселями и прозрачностью находятся в
`assets/interface/`. ICO встроен в ресурсы программы. Исходный образец из
Windows остаётся в `assets/up-reference/` и исключён из архива исходников.
Для повторного извлечения образца предусмотрен `scripts/export_up_icon.py`
(Windows, Python и Pillow).

## Установка инструментов и сборка

1. Скачайте **Build Tools for Visual Studio** с
   [официальной страницы Microsoft](https://visualstudio.microsoft.com/downloads/).
   На странице этот продукт может находиться в разделе инструментов.
2. Выберите нагрузку **Desktop development with C++** / «Разработка
   классических приложений на C++» (в Build Tools название также может
   отображаться как «Средства сборки C++»).
3. Убедитесь, что выбраны актуальные **MSVC C++ x64/x86 build tools**
   и **Windows SDK**. Windows 11 SDK также подходит для целевой Windows 10.
   Полная IDE, .NET, MFC и ATL для этой сборки не нужны.
4. После установки откройте PowerShell в папке проекта:

```powershell
.\scripts\Build-Windows.ps1
```

Полная пересборка, если менялись заголовки или сборочные параметры:

```powershell
.\scripts\Build-Windows.ps1 -Rebuild
```

Скрипт находит MSVC через `vswhere`, собирает `7z.dll`, `7zFM.exe`, `7zG.exe`,
`7-zip.dll`, `7z.exe`, затем компилирует и запускает `tests/ForkBehaviorTests.cpp`.
После успешных проверок создаются локальная папка программы, ZIP бинарников
и ZIP исходников в `build/`. Скрипт ничего не устанавливает и не регистрирует
расширение Проводника.

**Текущий статус:** инструменты установлены, сборка x64 и тесты C++ выполнены
успешно. Проверку интерфейса проводит владелец. Ресурсы FileTypes в собранной
DLL сверены с предоставленными ICO.

## Проверка перед публикацией

- На Windows 10 и Windows 11 проверить запуск, русскую и английскую
  локализации, переключение языка и восстановление режима «Таблица».
- Проверить прямые команды меню, состав контекстного меню, отсутствие
  Ctrl+Z для комментария и Alt+F12 для истории папок.
- Проверить окно «О программе», ссылку на 7-zip.org, отключённую кнопку GitHub
  до предоставления адреса, закрытие окна крестиком и клавишей Esc.
- Проверить оба формата даты, исходные форматы и переключение UTC.
- Пройти A → B → C, затем назад/вперёд; после возврата в B открыть D:
  старое направление вперёд в C должно исчезнуть. Проверить обе панели,
  переходы внутрь архивов/из архивов и удалённую папку в истории.
- Проверить системный выбор локальной папки, UNC-пути, длинный путь,
  выбор родителя ещё не созданного каталога и отмену выбора.
- Извлечь архив с одним файлом, одной пустой папкой, одной папкой с файлами,
  неявной папкой, несколькими файлами, несколькими папками, TAR.GZ,
  вложенный архив и архив с зашифрованными именами. Проверить распаковку
  выбранного архива и извлечение из уже открытого архива, включая плоский вид.
- После последовательной распаковки `files.zip` и `other.zip` в базу
  `Downloads\` должны предлагаться `Downloads\files\` и `Downloads\other\`.
  Проверить ручной путь, три кнопки истории, подсказки, отсутствие дублей,
  перезапуск и отмену без изменения истории.
- Проверить масштабирование 100%, 150%, 200%, длинные пути на кнопках,
  архивы с паролем и ошибки открытия/распаковки.
- При публикации добавить ссылку на репозиторий самого форка в README,
  опубликовать соответствующие исходники и проверить наличие всех лицензий
  и `THIRD_PARTY_NOTICES.txt` в бинарном пакете.
