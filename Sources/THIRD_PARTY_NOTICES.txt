Windows 10 file-type theme
--------------------------
Author as identified by the supplied theme.ini: masamunecyrus
Author's website: http://masamunecyrus.deviantart.com/
Collected from: https://github.com/RipplePiam/7zip-Theme

The supplied theme.ini lists the license as N/A and is preserved unchanged.
On 2026-10-28 the fork owner, pa4H, stated that permission had been obtained
and confirmed permission to publish these icons with sources on GitHub and
to distribute them in the compiled application. This records the owner's
confirmation; it does not invent a public license or relicense the artwork
under LGPL. No separate permission document was supplied in this project.

The ICO files are incorporated unchanged. The split archive resource uses
001.ico, corresponding to the existing .001 association. Existing archive
resource IDs and file associations are preserved.

The Up icon exported to assets/up-reference/ is a local reference extracted
from Windows common controls for redrawing. That folder is not included in
source distributions.

Custom Up icon
--------------
On 2026-10-28 the fork owner, pa4H, supplied up-updated.png (16x16) and
requested its use in the application. The supplied PNG is preserved unchanged
in assets/interface/. The accompanying ICO is a format conversion with the
same pixels and transparency and is embedded in the File Manager resources.
The application now uses this supplied icon instead of the Windows reference.
